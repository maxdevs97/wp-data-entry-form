# Bug Fixes - February 20, 2026

## Issues Resolved

### 1. ✅ Internal Server Error on Form Submission

**Problem:** 
- Users getting "Internal server error. Please try again or contact support." when submitting the form
- Error occurred after adding "What to Preserve" checkboxes

**Root Cause:**
- The form was sending a `preserve` object with checkbox data to the server
- Server's `submissionData` was missing required fields expected by `backlog.js` and `sheets.js`:
  - `requesterName`
  - `requesterEmail`
  - `priority`
  - `contentType`
- The `postTypes` and `certainPages` arrays were not being formatted properly for the backlog template

**Solution:**
1. **server.js** - Added missing fields to `submissionData`:
   ```javascript
   requesterName: 'Team Member', // Default value
   requesterEmail: 'team@sheragency.com', // Default value
   priority: 'Normal', // Default priority
   contentType: contentTypeDisplay.join(' | '), // For compatibility
   preserve: req.body.preserve || {}, // Store preserve preferences
   ```

2. **backlog.js** - Updated to handle array fields and preserve settings:
   - Added proper array formatting for `postTypes` and `certainPages`
   - Added default values for missing fields
   - Added preservation settings display in the task template

3. **sheets.js** - Added default values for all required fields:
   ```javascript
   data.requesterName || 'Team Member',
   data.requesterEmail || 'team@sheragency.com',
   data.contentType || data.contentTypeDisplay || 'N/A',
   data.priority || 'Normal',
   ```

### 2. ✅ Checkbox Styling Issues

**Problem:**
- Checkboxes had weird highlight/border effects
- Custom pseudo-elements causing rendering artifacts
- Checkboxes looked like buttons with borders

**Root Cause:**
- Complex custom checkbox design using:
  - Hidden native checkboxes
  - Custom `.checkbox-custom` span elements with pseudo-elements
  - Multiple border and shadow effects
  - Transition effects causing visual glitches

**Solution:**
1. **Replaced custom checkboxes with native HTML checkboxes:**
   - Removed `.checkbox-custom` span elements from HTML
   - Made native checkboxes visible and styled them simply
   - Used `accent-color` CSS property for consistent branding

2. **Simplified CSS:**
   ```css
   .checkbox-label input[type="checkbox"] {
     width: 20px;
     height: 20px;
     margin: 2px 0 0 0;
     cursor: pointer;
     flex-shrink: 0;
     accent-color: var(--accent-primary);
     border-radius: 4px;
   }
   ```

3. **Removed all pseudo-elements and complex transitions**

4. **Added 2-column grid layout for "What to Preserve" checkboxes:**
   ```html
   <div class="checkbox-group" style="display: grid; grid-template-columns: 1fr 1fr;">
   ```

5. **Improved responsive design:**
   - Checkboxes stack vertically on mobile
   - Proper spacing and hover effects
